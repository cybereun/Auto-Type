어떻게 고르나요

키를 누를 때마다 아래 과정을 거쳐 화면을 다시 그립니다.

두 가지로 읽기같은 키를 영어 그대로와 두벌식 한글로 각각 읽습니다.
점수 매기기영어는 3글자 연속 확률, 한국어는 음절 사용 빈도로 점수를 냅니다.
단서 더하기사전, 약어, URL, 앞 단어의 언어, 영어 + 조사 조합을 반영합니다.
가장 높은 쪽점수를 확률로 바꿔 1등을 보여 줍니다. 위 체험판의 막대가 그 확률입니다.

1분이면 설치

기존 Microsoft 입력기는 그대로 둡니다. 언제든 돌아갈 수 있습니다.

  1. Releases에서 AutoType-Setup.exe를 받습니다.
  2. 실행하고 관리자 권한 요청에 예를 누릅니다. SmartScreen이 막으면 추가 정보 → 실행.
  3. Win + Space로 Auto-Type (한영 자동)을 고릅니다.
  4. 이미 열려 있던 앱은 다시 실행하면 끝입니다.
